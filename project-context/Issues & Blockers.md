# ⚠️ Known Issues, Constraints & Blockers

This document details known limitations, edge cases, external API constraints, and operational gotchas across **Nudge AI**.

---

## 🛑 Known Limitations & Gotchas

### 1. Render Free-Tier Cold Starts
- **Symptom**: The first API request after 15 minutes of inactivity may take 30–50 seconds to respond.
- **Cause**: Render free web services spin down automatically when idle.
- **Mitigation**:
  - [.github/workflows/render-keepalive.yml](file:///c:/Users/suren/Nudge/.github/workflows/render-keepalive.yml) pings `https://nudge-backend-8fri.onrender.com/api/health` every 10 minutes.
  - The React frontend ([frontend/src/App.jsx](file:///c:/Users/suren/Nudge/frontend/src/App.jsx)) issues an immediate health probe on mount and pings every 5 minutes while the tab remains open.

### 2. Ephemeral Audio File Storage on Render
- **Symptom**: Audio files stored under `data/uploads/` disappear upon container redeployment or restart.
- **Cause**: Render web services run on ephemeral container filesystems.
- **Impact**: All meeting transcripts, decisions, action items, and embeddings in MongoDB Atlas remain permanently safe. Only the raw binary audio file (`.m4a`, `.webm`) on disk is wiped.

### 3. MongoDB Atlas Vector Search Index Requirement
- **Symptom**: `POST /api/rag/search` or `GET /api/rag/similar/{id}` returns empty results or logs an index warning.
- **Cause**: Vector search requires a one-time vector index to be defined in the Atlas UI (`nudge_meeting_vector_index` on `meeting_embeddings.embedding`).
- **Mitigation**: Call `GET /api/rag/setup-instructions` or follow the guide in [[Modules/Backend|Backend Module]] to configure the index in MongoDB Atlas.

### 4. Groq API Rate Limits
- **Symptom**: `429 Too Many Requests` during rapid consecutive transcriptions or large batch processing.
- **Cause**: Groq free tier enforces Requests Per Minute (RPM) and Tokens Per Minute (TPM) limits.
- **Mitigation**: [backend/utils/retry.py](file:///c:/Users/suren/Nudge/backend/utils/retry.py) wraps LLM and STT calls with exponential backoff (up to 3 retries with 1.5s initial delay).

### 5. Android Exact Alarm Permissions (Android 12+ / 14+)
- **Symptom**: Exact alarms fail to schedule on newer Android devices.
- **Cause**: Android 12 (API 31+) and Android 14 (API 34+) restrict `SCHEDULE_EXACT_ALARM` unless explicitly granted or declared as `USE_EXACT_ALARM`.
- **Mitigation**: [android/app/src/main/AndroidManifest.xml](file:///c:/Users/suren/Nudge/android/app/src/main/AndroidManifest.xml) declares both `SCHEDULE_EXACT_ALARM` and `USE_EXACT_ALARM`. [AlarmScheduler.kt](file:///c:/Users/suren/Nudge/android/app/src/main/java/com/nudge/ai/notifications/AlarmScheduler.kt) checks `canScheduleExactAlarms()` before calling `setExactAndAllowWhileIdle()`, falling back to `setAndAllowWhileIdle()`.

### 6. Chrome Extension Tab Audio Isolation
- **Symptom**: Extension captures Google Meet / Zoom meeting audio from participants, but does not capture the user's own spoken voice unless the tab loops back microphone audio.
- **Cause**: `chrome.tabCapture` captures output streams generated by the browser tab only.
- **Mitigation**: Use the Android native mobile app or web file upload for dual-sided room recording.
