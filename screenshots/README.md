# 📸 App & Web Screenshots

Drop your screenshots into this directory using the following recommended filenames:

| Filename | Description | Used in README |
|---|---|---|
| `home.png` | Android Home / Meetings List screen | Yes |
| `detail.png` | Android Meeting Detail (Summary, Decisions, Action Items) | Yes |
| `record.png` | Android Audio Recording Screen (Pulsing Mic & Self Name) | Yes |
| `action_items.png` | Android / Web Action Items & Deadline Reminders | Yes |
| `dashboard.png` | Web Dashboard Overview | Yes |
| `banner.png` | (Optional) Wide Hero / Banner Graphic | Yes |

*The main [README.md](../README.md) is pre-configured to display these images automatically.*
