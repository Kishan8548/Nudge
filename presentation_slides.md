# Slide 2: The Problem
**The Modern Meeting Crisis:**
In today's fast-paced corporate environment, professionals spend over 30% of their work week in meetings. However, the value generated by these meetings is frequently lost due to a lack of structured follow-up. 
* **Lost Accountability:** Action items are verbally assigned but rarely tracked efficiently. Team members forget what they committed to, or assume someone else is handling it.
* **Follow-Up Fatigue:** Project managers and team leads waste countless hours manually chasing down team members for updates via email or Slack.
* **Information Silos:** Meeting notes, if taken at all, are scattered across Google Docs, Notion, or personal notebooks, making it incredibly difficult to recall past decisions or find context weeks later.

---

# Slide 3: The Solution – Introducing Nudge AI
**What is Nudge?**
Nudge is a fully autonomous Agentic AI system that lives seamlessly in your browser. It listens to your meetings, understands the context, and handles the entire post-meeting workflow end-to-end without human intervention.
* **Live Capture:** A lightweight Chrome Extension captures live meeting audio from platforms like Google Meet or Zoom.
* **Intelligent Extraction:** Instead of just transcribing, Nudge autonomously extracts core decisions, specific action items, responsible owners, and firm deadlines.
* **The "AI Project Manager":** Nudge goes beyond note-taking. It acts as an autonomous project manager by proactively tracking the status of assigned tasks and pinging team members on Slack and via Email when they miss their deadlines.

---

# Slide 4: Core Features & The "Wow" Factor
* **Live Audio Capture & Groq Whisper:** Records browser audio directly from the source and transcribes it in milliseconds. By utilizing Groq's LPU technology, transcription happens at record-breaking speeds.
* **Agentic Extraction Pipeline:** Nudge uses a multi-agent LangGraph topology to intelligently pull structured data from messy human conversation. It doesn't just summarize; it categorizes data into strict JSON schemas.
* **Semantic Memory (Nomic AI Integration):** Automatically chunks and vectorizes meeting transcripts using the **Nomic Embeddings API**. This powers our advanced RAG (Retrieval-Augmented Generation) system. Users can instantly find past decisions and similar action items based on semantic context, not just rigid keyword searches.
* **Smart Escalation Engine (Slack + SMTP):** A background chron-job that operates 24/7. It sends friendly, color-coded reminders via Slack Webhooks and SMTP Email routing. If a task remains ignored after multiple reminders, the engine automatically escalates the issue by tagging the manager with a red-alert notification.
* **Beautiful Analytics Dashboard:** A dynamic, glassmorphic UI built in React that provides managers with real-time KPI tracking. It features donut charts for status breakdowns, bar charts for meeting frequency, and a "Leaderboard" showing completion rates for individual team members.
* **Auto-Summaries & PDF Export:** Generates 3-4 sentence executive summaries in seconds and exports clean, professional, print-ready PDFs of the meeting notes and tasks with a single click.

# Slide 5: Architecture & Tech Stack Details
Nudge is built on a highly scalable, modern, and ultra-fast tech stack designed for enterprise readiness.
* **Frontend:** React + Vite + Vanilla CSS. The UI is designed with a premium, glassmorphic aesthetic to ensure a beautiful user experience.
* **Backend:** Python + FastAPI. Chosen for its extreme performance, asynchronous capabilities, and native Pydantic validation.
* **Database:** MongoDB Atlas. Utilized not just for document storage, but heavily leveraging **MongoDB Native Vector Search** to power the semantic memory and RAG features.
* **Agentic Framework:** **LangGraph**. We use a `StateGraph` implementation to allow for cyclic, stateful agent workflows, enabling the AI to pause, reflect, and make decisions rather than executing a simple linear chain.
* **LLM Providers:** 
  * **Groq (Llama-3.3-70b-versatile):** Chosen specifically for its ultra-low latency reasoning, allowing the extraction agents to process transcripts almost instantaneously.
  * **Nomic AI:** Provides state-of-the-art semantic text embeddings for our vector database.
* **Integrations:** Slack Webhooks (instant messaging), SMTP Email Server (guaranteed delivery routing), and Chrome API (background offscreen audio capture).

# Slide 6: How the Agent Works (The Brain & Workflow)
Nudge is not a simple "ChatGPT wrapper." It is an autonomous workflow capable of reasoning. Here is the step-by-step pipeline:
1. **Transcription & Pre-processing:** The extension sends audio to the FastAPI backend, which is instantly transcribed by Groq Whisper.
2. **The Extraction Agent:** A specialized prompt instructs the Llama-3 LLM to read the raw transcript and identify hidden action items and core decisions.
3. **The Confidence & Review Node:** (Human-in-the-Loop) If the AI is under 80% confident about who owns a task or what the exact deadline is, the LangGraph execution pauses and flags the item for manual human review, ensuring 100% accuracy on critical tasks.
4. **Vectorization & Storage:** Structured data is saved securely to MongoDB. Simultaneously, the backend calls the Nomic API to generate high-dimensional embeddings for the transcript, pushing the vectors into MongoDB Atlas.
5. **The Follow-Up Agent (Cron Task):** A resilient background scheduler wakes up periodically, scans the database for overdue tasks, and fires escalating, multi-channel alerts (Slack + SMTP).

# Slide 7: Business Value & Real-World Impact
* **Massive Time Savings:** Completely eliminates the need for manual note-taking, formatting, and post-meeting alignment emails.
* **Dramatically Increases Task Completion:** The proactive, multi-channel reminder system gently "nudges" employees, ensuring that no action item is forgotten and significantly reducing project bottlenecking.
* **Unlocks Data-Driven Insights:** For the first time, managers can view analytics on *who* is consistently delivering on time, what the escalation rates are, and which departments are falling behind.
* **Ultra-Fast & Cost-Effective:** Powered by Groq's LPU inference, Nudge processes hours of meetings in seconds at a fraction of the cost of traditional GPU-bound LLM pipelines.
